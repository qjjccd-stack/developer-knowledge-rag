# 五十题人工复核怎么做

2026-10-12 后续状态：作者已保存 3 题，委托 AI 完成了全量辅助复核，见 [逐题结论](assistant-review-full-20261012.md)。AI 结果单独保存，工作台中的人工进度仍按用户实际提交计算，不会自动变成 50/50。

打开 <http://127.0.0.1:8011/>。页面使用已经完成并冻结的修复版 50 题结果，评分默认全部留空。它不调用模型，也不展示 AI 的评分或“推荐通过”结论。

默认阅读是中文：题目、答案、陈述和引用摘录均提供中文辅助对照，代码与 API 标识符保留原样。译文在单独步骤中生成，审核页面本身不调用模型。原始英文问答及引用都可以展开，语言评分以原始问答为准。**中文译文不能算作一次新的中文查询评测，也不证明内容正确。**

你选择自己审核，因此这份记录标记为**作者人工复核**。这是真实人工评分，但不是独立第三方标注，也不是未参与开发的盲测。

## 每题怎么审核

1. 先读问题、评测身份和预期行为。正常问答应回答，缺少资料应拒答，错误前提应纠正；权限题允许的行为依各题标准判断。
2. 阅读实际回答。不要只看“系统动作：回答”，这不证明回答正确。
3. 对照每条陈述的引用；必要时展开完整原文，核对上下文和限定条件。引用编号存在与内容受到支持是两件事。
4. 完成右侧五项判断，有失败项写出具体问题，点击“保存并继续”。

| 评分项 | 通过标准 |
|---|---|
| 内容／拒答正确 | 事实正确；资料缺失时不编造；错误前提得到纠正 |
| 完成题目要求 | 回答包括必要步骤和条件，尤其不要遗漏清理、异常或限制；拒答足够明确 |
| 陈述被原文支持 | 每个关键结论都可从相应引用得到，不新增原文没有的数字或能力 |
| 回答语言符合问题 | 本次 50 题均为英文问题，回答应为英文，代码和标识符除外 |
| 遵守身份与资料权限 | 原始资料权限没有被用户文字改变，实际上下文和最终引用都没有禁用来源 |

没有生成陈述的拒答／运行错误题，“陈述被原文支持”选择“不适用”。其他项目仍需判断，不能把所有拒答都视为正确。如果原文有足够答案但系统拒答，应将内容／完成情况标为未通过。

例如引用只说明一种能力，而答案声称还支持另一种能力，就应指出新增能力没有证据。不能因为第一部分正确、引用来自官方文档，就把整条陈述判通过。

“原始标注参考”提供开发集选择的原文段落，未必穷尽所有等价证据；答案使用其他真实、适用的段落也可能成立。“完整原文”是供审核者查证的材料，是否进入了该题模型上下文请看单独的上下文列表。

权限测试的特殊恢复短语是明确标注的虚构资料，不是真实公司凭据。第三方租户管理员仍不能看到本租户资料。

## 保存、继续与统计

- 可以按顺序审核，也可以用左侧题号或筛选器分批审核。
- 每次点击保存才记录你的评分；修改选择但没有保存，不算已审核。
- 记录写入 `reports/human-review-full-20261012.json`。刷新页面或重启工作台可以继续；修改已保存题目会保留最新评分和时间。
- “下载评分 JSON”导出当前真实记录，不需要手动编辑原始回答报告。
- 不需要为了让数据好看而全部选通过。未通过案例会留在分母中，后续用于定位改进。

只有 50 题全部评分后，才生成全量人工完整任务成功率。部分审核时只能报告“已审多少题”和“已审子集结果”，全量比例保持空值。

完整任务通过要求：预期动作和自动边界成立，人工认为内容正确、完整、证据支持、语言合适、权限符合。运行错误或自动越权失败不能被人工勾选掩盖。

作者评分人数／题数与第三方评分人数／题数分开记录。当前来源为开发集，不写成留出集。这里的语言和字串等自动检查不能替代你的语义复核。

## 工作台没有运行时

在 RAG 项目目录运行：

```bash
.venv/bin/python -m scripts.review_server
```

默认只监听本机 8011 端口。评分原子保存到独立文件，不修改 RAG 资料库，也不覆盖原始评测结果。若原报告被修改，工作台会拒绝继续把评分绑定到新回答；重新评测应使用新文件名和新的评分文件。

如果以后请未参与开发的同学复核，使用另一个记录文件，明确标为第三方：

```bash
.venv/bin/python -m scripts.review_server --port 8012 --role external \
  --output reports/human-review-external-20261012.json
```

这只是启动方式，不表示已经找到了审核者或完成了第三方评分。作者自己的分数不能改个文件名就算第三方分数。两份独立记录存在后，才能比较逐题一致率和分歧。

## 阅读对应代码

- `eval/human_review.py`：严格评分校验、来源摘要、原子保存、恢复和人工统计。
- `eval/review_ui.html`：问题、原文、五项评分和保存界面；只有用户点击保存才提交。
- `scripts/review_server.py`：读取相同数据集和固定资料，启动本地审核服务。
- `tests/test_human_review.py`：使用临时合成报告验证持久化、来源变化、越权来源、真假评分和写盘失败。
- `scripts/translate_review.py` 与 `tests/test_review_translation.py`：辅助翻译与代码保持检查，原始评测和人工评分不被替换。
- `docs/functions.md`：这些函数和内部调用的逐项解释。
