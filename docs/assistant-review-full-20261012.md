## 三题为什么需要修改

### Q014：把调用异步函数与等待协程混为一谈

核心回答“await 在 async def 函数体中使用”符合问题；额外一句却声称异步函数只能从异步函数调用。同步代码也可以调用异步函数，得到协程对象，再用 asyncio.run 运行；已用一个无网络的小程序验证。[Python 官方文档](https://docs.python.org/3/library/asyncio-task.html)区分了协程函数、协程对象以及运行方式。

原因：检索到的教程原文本身使用简化教学表述，生成模型照搬了这一附加结论。因此引用检查通过，事实严谨性仍不通过。改进应让回答聚焦 await 的问题，删去不必要的普遍化推论；如扩展讲解，应补入权威资料区分调用与运行。

### Q027、F005：把教程里的签名 JWT 泛化为全部 JWT

当前 FastAPI 教程讨论的签名令牌内容可读；回答没有保留这个场景范围，直接说 JWT 都不加密。[RFC 7519 第 3 节](https://www.rfc-editor.org/rfc/rfc7519.html#section-3)也定义了 JWE 加密形式。因此两题按冻结资料及参考答案都能通过，但按无歧义事实表达不应直接判通过。

改进：限定为“本教程使用的签名 JWT”；若需要解释所有 JWT 类型，先补入标准资料，再讨论签名和加密。参考题及参考答案也应在新版本中明确“本教程的签名 JWT”，保存版本记录，不能修改旧题后宣称旧版本分数提升。
